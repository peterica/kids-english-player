# 콘텐츠 정책 (Content Policy)

이 저장소는 아이 영어 학습용 **YouTube 영상 선별 목록(curation)** 을 포함한다
(`prisma/seed-content.ts`, 2026-08 기준 23개 채널 / 526편).
공개 전 오해를 막기 위해 다음을 명확히 한다.

---

## 1. 이 프로젝트가 저장하는 것

| 저장 | 저장하지 않음 |
|---|---|
| YouTube 영상 ID | 영상 파일 |
| 영상 제목 · 채널 이름 | 자막 · 오디오 · 썸네일 이미지 파일 |
| 자체 부여한 Level(1–5) · 길이 | 다운로드본 · 캐시본 |

즉 이 저장소에 있는 것은 **공개된 YouTube 영상을 가리키는 링크와 메타데이터**이며,
어떤 영상도 복제·재호스팅·배포하지 않는다.

## 2. 재생 방식

재생은 전적으로 **YouTube IFrame Player API**(공식 임베드 플레이어)로 이뤄진다.

- 영상은 YouTube 서버에서 직접 스트리밍된다
- 조회수 · 광고 수익 · 통계는 모두 원저작자에게 귀속된다
- 원저작자가 임베드를 막거나 영상을 내리면 이 앱에서도 즉시 재생되지 않는다
- 업로더가 임베드를 허용하지 않은 영상(ERROR_150)은 목록에 넣지 않는다

## 3. 상표 · 저작권

`Bluey`, `Peppa Pig`, `Caillou`, `Super Simple Songs` 등 목록에 나오는 채널·프로그램 이름은
**각 권리자의 상표이며 저작물**이다.

- 이 프로젝트는 해당 권리자와 **제휴·후원·승인 관계가 없다**
- 이름은 어떤 채널의 영상인지 식별하기 위한 **사실 기술(nominative use)** 로만 사용한다
- 이 프로젝트는 YouTube / Google 과도 무관하다

## 4. 라이선스 구분

| 대상 | 라이선스 |
|---|---|

| `prisma/seed-content.ts` 의 선별 목록 | 사실 데이터의 모음이며, 참조된 **영상 자체의 권리는 각 저작권자에게 있다** |

MIT 라이선스는 **코드에 적용되며, 링크된 영상에 대한 어떤 권리도 부여하지 않는다.**

## 5. 삭제 요청

권리자 또는 그 대리인이 목록에서 특정 채널·영상의 제거를 원하는 경우,
GitHub 이슈 또는 저장소에 기재된 연락처로 알려주면 **확인 후 목록에서 제거한다.**
이 저장소는 영상을 호스팅하지 않으므로, 제거는 링크와 메타데이터 삭제를 의미한다.

## 6. 목록의 한계

- 영상은 **삭제되거나 비공개로 바뀔 수 있고**, 지역 제한이 생길 수 있다
- Level(1–5)은 공인된 기준이 아니라 **이 프로젝트의 주관적 분류**다
- 목록이 최신이거나 완전하다는 보장은 없다

목록을 바꾸는 방법은 두 가지다.

1. 운영자 화면(`/admin/content`) — 영상 추가 · 수정 · 노출 해제
2. `prisma/seed-content.ts` 직접 수정 후 `npm run db:seed` (idempotent)

seed 는 부모가 직접 등록한 영상과 Collection 을 건드리지 않는다.
