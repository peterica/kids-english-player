# 개인정보 안내 (Privacy)

이 앱은 **가정별 self-hosted 인스턴스**다. 중앙 서버도, 운영 회사도, 계정 서비스도 없다.
따라서 여기서 말하는 "저장"은 전부 **당신이 띄운 서버의 SQLite 파일 하나**(`data/app.db`)를 뜻한다.

## 한눈에

| | |
|---|---|
| 외부로 전송되는 개인정보 | **없다** |
| 분석 도구 · 트래킹 · 광고 SDK | **없다** |
| 개발자가 볼 수 있는 데이터 | **없다** (서버가 당신 것이므로) |
| 데이터 위치 | `data/app.db` 파일 하나 |
| 데이터 삭제 방법 | 그 파일을 지우면 끝 |

## 수집하지 않는 것

```text
이메일 · 전화번호 · 실명 · 생년월일 · 성별 · 주소
외부 계정 식별자(OAuth 등) · 결제 정보 · 위치 · 기기 식별자
```

계정은 **아이디와 비밀번호만**으로 만든다. 아이는 계정이 아니라 **프로필**이며 로그인하지 않는다.

## 저장하는 것

| 데이터 | 내용 | 비고 |
|---|---|---|
| 로그인 아이디 | `username` | 서버 내부 식별용 |
| 비밀번호 | scrypt 해시 | 평문·복호화 가능한 형태로 저장하지 않음 |
| 가정 이름 | 기본값 `우리 가족` | 입력은 선택 |
| 아이 프로필 | 별명, 허용 Level, 선호 Channel | **실명을 요구하지 않는다** |
| 시청 기록 | 영상별 진행률·시청 시간·완료 여부·시각 | `childId` 로만 연결 |
| Collection | 아이별로 담은 영상 목록과 순서 | |
| 오류 신고 | 부모가 직접 입력한 설명 | 자유 입력이므로 개인정보를 적지 않는 편이 좋다 |

## 외부로 나가는 요청

앱이 외부에 보내는 요청은 **YouTube 관련 세 가지뿐**이며, 어느 것에도 계정·아이·시청기록이 실리지 않는다.

| 대상 | 목적 |
|---|---|
| `www.youtube.com/iframe_api` + 임베드 플레이어 | 영상 재생 (공식 플레이어) |
| `i.ytimg.com` | 썸네일 이미지 (핫링크, 저장하지 않음) |
| `www.youtube.com/oembed` | 부모가 직접 영상을 추가할 때 제목·업로더 자동 채움 |

YouTube 임베드 플레이어는 **YouTube 자체의 쿠키·정책**을 따른다. 이 부분은 이 앱이 통제하지 않는다.
쿠키를 줄이고 싶다면 리버스 프록시 단에서 `youtube-nocookie.com` 도메인을 쓰도록 조정할 수 있다.

## 로그

애플리케이션이 개인정보를 로그로 남기지 않는다. 예상치 못한 오류만 서버 콘솔에 기록한다.
다만 **웹서버·컨테이너 런타임이 만드는 접근 로그에는 접속 IP 가 남을 수 있다.**
이는 프레임워크·인프라의 기본 동작이며, 보존 기간 정책은 서버를 운영하는 사람이 정한다.

## 남아 있는 식별 가능성 (정직하게)

컬럼에서 이메일을 없앴다고 해서 "식별 불가"가 되는 것은 아니다. 남은 경로는 다음과 같다.

1. **사용자가 직접 넣는 문자열** — 아이디나 아이 별명에 실명을 넣으면 그대로 저장된다
2. **시청 행동 기록** — 아이별로 언제 무엇을 얼마나 봤는지가 누적된다
3. **인프라 접근 로그** — 위의 IP

전부 **당신의 서버 안에만** 있지만, 서버 자체가 유출되면 함께 노출된다. 백업 파일 관리에 주의한다.

## 아이 데이터에 대해

이 앱은 아이가 쓰는 화면을 포함하지만 **아이에게서 직접 정보를 수집하지 않는다.**
아이 프로필은 부모가 만들고 부모가 관리한다.

가정 내 개인 사용을 넘어 **여러 가정에 서비스하거나 유료화한다면**,
COPPA·GDPR·국내 개인정보보호법(만 14세 미만 법정대리인 동의) 등 별도 의무가 생긴다.
이 저장소는 그런 용도를 전제로 만들어지지 않았다.

## 데이터 내보내기 · 삭제

```bash
# 백업 — 파일 하나를 복사하면 끝
cp data/app.db backup/app-$(date +%Y%m%d).db

# 콘텐츠 목록만 문서로 내보내기 (계정·아이·시청기록은 제외된다)
npm run content:export

# 완전 삭제
docker compose down && rm -rf data/
```
