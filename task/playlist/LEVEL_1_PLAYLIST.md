# Kids English Player — Level 1 Playlist

- 기준일: 2026-08-28
- 대상: 7세
- 난이도 기준점: Caillou보다 쉬운 단계
- 목표: 영어 소리와 기본 표현에 익숙해지고, 짧은 영어 스토리까지 자연스럽게 이어가기
- 구성: Super Simple Play with Caitie → Pocoyo English
- 권장 운영: 하루 1편, 필요하면 같은 영상을 2~3회 반복
- 등록 방식: 아래 순서대로 `sequence` 부여

## Level 1 학습 목표

1. 영어 소리를 거부감 없이 듣는다.
2. 반복되는 단어와 표현을 자연스럽게 기억한다.
3. 화면의 행동과 영어 표현을 연결한다.
4. 짧은 질문에 익숙해진다.
5. 마지막에는 Pocoyo의 짧은 이야기 흐름을 영어로 따라간다.

```text
노래 + 행동
→ 기본 어휘
→ 질문과 대답
→ 상황 설명
→ 짧은 스토리
```

# 진행 기준

완료율만으로 Level 1 통과를 판단하지 않는다.

```text
A. 영상을 거부하지 않고 본다.
B. 반복 표현을 따라 말하는 경우가 생긴다.
C. 화면과 단어를 연결한다.
D. Pocoyo에서 사건의 흐름을 대략 이해한다.
```

# 운영 메모

60~100분짜리 compilation은 가급적 피한다.

현재 Kids English Player는 YouTube URL 하나를 하나의 학습 영상으로 관리하므로:
- 완료 기준 90%가 너무 길어질 수 있다.
- 실제로 어떤 에피소드를 보았는지 구분하기 어렵다.
- 반복 학습 관리가 어렵다.

향후 다음 필드를 지원하면 compilation도 활용하기 쉬워진다.

```text
startSeconds
endSeconds
```
