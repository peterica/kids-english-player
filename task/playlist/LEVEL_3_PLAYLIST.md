# Level 3 학습 목표

Level 3부터는 영어를 `단어`나 `짧은 문장` 단위로만 듣지 않고,
**대화의 흐름과 상황 전체를 따라가는 연습**을 시작한다.

핵심 목표:

1. 짧은 질문과 대답을 자연스럽게 듣는다.
2. 등장인물 사이의 대화가 이어져도 이야기 흐름을 놓치지 않는다.
3. 학교, 친구, 가족, 병원, 놀이 같은 익숙한 상황에서 영어를 추론한다.
4. 감정 표현과 이유 표현을 상황과 연결한다.
5. 한 문장을 완벽히 해석하지 못해도 전체 사건의 원인과 결과를 이해한다.

전체 흐름:

```text
반복 표현
→ 짧은 대화
→ 일상 상황
→ 감정과 이유
→ 여러 인물의 대화
→ Caillou 수준의 스토리 이해
```

# Level 3 진행 기준

Level 3의 핵심은 단어를 몇 개 아는지가 아니다.

다음을 관찰한다.

```text
A. Caillou를 영어 그대로 보는 것을 크게 거부하지 않는다.
B. 화면만 보고 추측하는 수준을 넘어 일부 대사를 함께 듣는다.
C. 질문과 대답의 순서를 따라간다.
D. 등장인물의 감정 변화 이유를 대략 이해한다.
E. "무슨 일이 있었어?"라고 물으면 주요 사건을 설명할 수 있다.
F. friend / help / school / doctor / together 등의 반복 표현을 상황과 연결한다.
```

완벽한 이해는 필요 없다.

예를 들어:

```text
"친구가 의자를 부숴서 Caillou가 속상했는데,
나중에 같이 축구했어."
```

정도로 이야기 핵심을 말할 수 있다면
전체 영어 문장을 해석하지 못해도 충분한 진전으로 본다.

# 부모 질문 방법

영상이 끝난 뒤 영어 시험처럼 질문하지 않는다.

추천 질문:

```text
누가 나왔어?
어디에 갔어?
무슨 일이 있었어?
Caillou는 왜 기분이 안 좋았어?
마지막에는 어떻게 됐어?
```

아이가 한국어로 답해도 괜찮다.

Level 3의 목적은:

```text
영어 → 의미 이해
```

이지,

```text
영어 → 영어로 답변
```

까지 요구하는 단계는 아니다.

---

# 권장 반복 방식

Level 3부터는 같은 영상을 반복해서 보는 가치가 커진다.

추천:

```text
1회차: 그냥 보기
2회차: 이미 아는 이야기로 영어 소리 다시 듣기
3회차: 아이가 좋아하는 영상만 선택 반복
```

모든 영상을 반드시 2~3번 볼 필요는 없다.

아이가 좋아하는 에피소드의 자연스러운 반복을 우선한다.

# Level 4 진입 기준

다음 정도면 Peppa Pig 입문을 시작할 수 있다.

```text
- Caillou 한 편을 영어 그대로 끝까지 볼 수 있다.
- 주요 사건을 대략 설명할 수 있다.
- 여러 등장인물이 대화해도 누가 누구에게 말하는지 대부분 따라간다.
- 익숙한 일상 표현은 번역 없이 행동과 연결된다.
- 대사가 조금 빨라져도 영상 시청 자체를 포기하지 않는다.
```

Level 4 방향:

```text
Caillou
+
Peppa Pig 입문
```

목표:

```text
명확하고 느린 일상 대화
→ 더 빠른 가족·친구 대화
→ 자연스러운 turn-taking 듣기
```
