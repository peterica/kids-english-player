# Kids English Player — Level 4 Playlist

- 기준일: 2026-08-28
- 대상: 7세
- 난이도: Level 4
- 기준점: Caillou보다 한 단계 빠르고 자연스러운 대화
- 핵심 구성: Caillou Bridge → Peppa Pig
- 목표: 명확하고 느린 일상 대화에서, 더 빠른 가족·친구 간 자연스러운 turn-taking 대화로 넘어간다.
- 권장 운영: 하루 1편, Peppa 초반 3~4편은 필요하면 2회 반복
- Kids English Player 등록: Level 3의 sequence 360 다음부터 이어서 등록

# Level 4 학습 목표

Level 4부터는 다음 변화가 핵심이다.

```text
Caillou:
한 사람이 비교적 천천히 설명
→ 상황이 명확함
→ 대화 간격이 큼

Peppa Pig:
여러 사람이 빠르게 주고받음
→ 문장이 짧지만 전환이 빠름
→ 가족/친구 간 자연스러운 표현 증가
```

핵심 목표:

1. 여러 인물이 빠르게 번갈아 말해도 누가 말하는지 따라간다.
2. 짧은 일상 문장을 번역하지 않고 상황과 연결한다.
3. 질문 → 대답 → 반응의 흐름을 놓치지 않는다.
4. 가족과 친구 사이의 자연스러운 표현을 반복해서 듣는다.
5. 5~7분 정도의 Peppa Pig 에피소드를 영어 그대로 보는 데 익숙해진다.

전체 흐름:

```text
Caillou 복습
→ 익숙한 행동
→ 가족 대화
→ 친구 대화
→ 학교/외출
→ 빠른 turn-taking
```

# Level 4 진행 기준

Level 4에서는 단어를 얼마나 많이 아는지보다
**대화의 속도를 따라가는가**가 중요하다.

다음을 관찰한다.

```text
A. Peppa Pig를 영어 그대로 끝까지 본다.
B. 여러 인물이 말해도 화자를 대략 구분한다.
C. 질문 → 대답 → 반응 흐름을 따라간다.
D. 익숙한 표현은 번역 없이 행동과 연결한다.
E. 주요 사건을 순서대로 설명할 수 있다.
F. 대사를 모두 이해하지 못해도 영상 자체를 포기하지 않는다.
```

---

# Level 3과 Level 4의 차이

```text
Level 3
Caillou 중심
→ 비교적 느린 대화
→ 한 장면의 의미 파악

Level 4
Peppa Pig 중심
→ 빠른 turn-taking
→ 여러 인물
→ 장면 사이 사건 연결
```

예를 들어 아이가 Peppa를 본 뒤:

```text
"Peppa가 자전거를 탔는데 안전하게 타야 해서
헬멧을 쓰고 연습했어."
```

정도로 설명할 수 있다면
영어 문장 전체를 해석하지 못해도 충분하다.

---

# 부모 질문 방법

Peppa부터는 질문을 너무 많이 하지 않는 것이 좋다.

한 편당 2~3개면 충분하다.

추천:

```text
누가 나왔어?
어디에 갔어?
무슨 일이 생겼어?
왜 그렇게 했어?
마지막에는 어떻게 됐어?
```

영어로 답하게 할 필요는 없다.

목표는 계속:

```text
영어 소리
→ 의미
```

직접 연결이다.

---

# 반복 운영 권장

Peppa 초반에는 다음 방식이 효과적이다.

```text
Day 1: 처음 보기
Day 2: 다른 영상
Day 3: 다른 영상
Day 4: 가장 좋아했던 Peppa 다시 보기
```

정해진 모든 영상을 강제로 반복시키기보다
아이 스스로 좋아한 영상을 반복하도록 허용한다.

이미 줄거리를 알고 있는 영상은
두 번째 시청에서 화면보다 영어 소리에 더 집중하기 쉽다.

---

# Level 5 진입 기준

다음 정도라면 Level 5로 넘어갈 수 있다.

```text
- Peppa Pig의 일반적인 5~7분 에피소드를 영어로 편하게 본다.
- 가족/친구 여러 명의 대화를 대부분 따라간다.
- 사건의 원인과 결과를 대략 설명한다.
- 화면에 직접 보이지 않는 감정이나 의도도 일부 추론한다.
- 영어가 조금 빨라도 시청을 중단하지 않는다.
```

Level 5 방향:

```text
Peppa Pig
+
Bluey 입문
```

목표:

```text
유아 대상의 명확한 영어
→ 실제 가족 대화에 가까운 자연스러운 영어
→ 생략 / 유머 / 감정 / 암묵적 의미 이해
```
